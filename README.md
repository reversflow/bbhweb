# BBH Culture Collective

Create a modern, premium and fully responsive website for a French urban culture association called “BBH Association”.

The website must be in French.

Main goal:
BBH is a cultural association based in Hauts-de-France that promotes urban culture through music events, rap showcases, open mics, artist support, creative workshops and collaborations. The website should feel serious enough for partners, bars, cities, schools and cultural institutions, but still underground, young, urban and artistic.

Visual direction:
Use a dark premium aesthetic inspired by underground rap, streetwear and live events.
Main background: deep black / near black.
Text: strong white and soft grey.
Accent colors: electric blue, deep red, subtle purple glow.
Use the palette inspired by concert lights, studio photos, night photography and streetwear visuals.
The site should feel like:
- urban culture
- rap scene
- underground events
- young independent artists
- community
- premium streetwear/studio vibe

Design style:
Minimal but powerful.
Large typography.
Strong spacing.
Rounded image cards.
Soft gradients.
Subtle glow effects in electric blue and red.
Modern cards with hover animations.
Smooth scrolling.
Responsive mobile-first layout.
No generic corporate look. It must feel cultural, urban and alive.

Temporary logo:
Use simple text “BBH” in a clean elegant style in the navbar for now. The real logo will be added later.

Navigation:
Top sticky navbar with:
- Accueil
- Événements
- Ateliers
- Artistes
- À propos
- Contact

Add a mobile hamburger menu.
